# Платформенный код основного кода модулей — и почему он не в общем коде.
#
# Общий код пишется в commonMain; в jvmMain, androidMain и iosMain остаётся
# только то, что платформа делает иначе. Каждый файл таких наборов записан
# здесь строкой «путь — причина»; путь, оканчивающийся на «/», покрывает
# каталог целиком. Новый файл без записи и запись без файла не проходят
# проверку PlatformCodeTest модуля testing.

# Оснастка проверок: сцены отрисовки рисует настольный Compose, стенд ядра
# и подставной кабинет живут на JVM. В приложение модуль не входит.
testing/src/jvmMain/ — оснастка проверок на JVM: сцены отрисовки, стенд ядра, подставной кабинет
