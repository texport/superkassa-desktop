# superkassa-desktop

Кассовое рабочее место для настольных систем: Compose Multiplatform и Material 3,
одна сборка под macOS, Windows и Linux.

## Что это

Приложение — только лицо кассы. Вся фискальная работа идёт в узле
`superkassa-server`, запущенном в режиме `DESKTOP` на той же машине; приложение
обращается к нему по HTTP на `127.0.0.1:8080`.

Своего состояния приложение не хранит намеренно: закрытие окна посреди смены
ничего не теряет, а два запущенных окна не разойдутся в счётчиках.

## Запуск

Сначала узел:

```
cd ../superkassa-server && ./gradlew :server:bootRun
```

Затем приложение:

```
./gradlew run
```

Установочный образ для текущей системы:

```
./gradlew packageDistributionForCurrentOS
```

## Разделы

| Раздел | Что делает |
| --- | --- |
| Главная | Состояние кассы и смены, наличные, документы смены, печать и досылка |
| Продажа | Штрихкод и ручной ввод позиций, виды оплаты, принято и сдача |
| Возврат | Возврат по чеку-основанию из текущей смены |
| Деньги | Внесение и изъятие с остатком в ящике |
| История | Журнал за сутки с фискальными признаками |
| Очередь | Ждущие задачи отдельно от отправленных, повтор неудачных |
| Кассиры | Список, заведение, смена пина, удаление |
| Настройки | Выбор и заведение кассы, вход кассира, диагностика ОФД |

## Решения, которые стоит знать

**Состояние узла видно всегда.** Полоса вверху показывает связь с узлом,
автономный режим и блокировку на любом разделе: разрыв связи кассир должен
увидеть до того, как пробьёт чек, а не после.

**Отказ узла и недоступность узла разделены.** При отказе кассир правит чек,
при недоступности зовёт обслуживание. Одинаковое сообщение увело бы его не туда,
поэтому они показаны по-разному и код отказа выводится рядом с текстом.

**Пин живёт только в памяти.** Он даёт право на фискальные команды, и записывать
его на диск нельзя.

**Кредит и тара кассиру не предлагаются.** Эти виды оплаты объявлены устаревшими
и в схеме протокола 2.0.4 отсутствуют; узел такой чек отвергнет.

**Разделители в суммах заданы escape-последовательностями.** Неразрывный пробел
в исходнике неотличим от обычного, и однажды он уже развёл показ и разбор: сумма
`1 200` с обычным пробелом не принималась.
